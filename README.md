# ビジネス資料設計プロンプトメーカー

「ビジネス資料設計プロンプトメーカー」（リポジトリ名：`business-doc-prompt-maker`）は、利用者がフォームに沿って情報を入力すると、ChatGPTに貼り付けるための高品質な資料作成プロンプトを自動生成するWebアプリです。

このアプリ自体ではPowerPointファイルを作成しません。最終的に出力するのは、ChatGPTに貼り付けるためのプロンプトです。

## アプリ概要

- React + TypeScript + Viteで構築したフロントエンドのみのWebアプリです。
- バックエンドや外部API連携はありません。
- 入力内容はブラウザの`localStorage`に自動保存されます。
- 生成されたプロンプトはワンクリックでコピーできます。
- 入力内容はJSON形式でエクスポート・インポートできます。
- 白背景、ネイビー系、カード型レイアウトを基本にした業務利用向けのシンプルなUIです。

## 起動方法

```bash
npm install
npm run dev
```

開発サーバーのURLが表示されたら、ブラウザでアクセスしてください。

本番ビルドを確認する場合は以下を実行します。

```bash
npm run build
npm run preview
```

## 使い方

1. 「基本情報」「資料のゴール」「読み手情報」などのカテゴリを開きます。
2. わかる範囲で入力します。すべての項目は任意入力です。
3. 「不足情報チェック」を確認し、必要に応じて主要項目を追加入力します。
4. 右側の「生成プロンプトのプレビュー」で内容を確認します。
5. 「コピー」ボタンでプロンプトをコピーし、ChatGPTに貼り付けます。
6. 必要に応じて「JSONエクスポート」で入力内容を保存し、後日「JSONインポート」で復元します。
7. 最初からやり直す場合は「リセット」ボタンを使います。

## 入力項目の説明

### 基本情報

資料タイトル、資料の種類、目的、対象者、利用シーン、使用言語、希望枚数、発表時間など、資料全体の前提を指定します。

### 資料のゴール

一番伝えたいこと、相手に取ってほしい行動、判断してほしい事項、残したい印象、成功の状態を入力します。資料のストーリーを明確にするための項目です。

### 読み手情報

読み手の属性、前提知識、関心事、不安点、響きやすい表現を入力します。読み手に合わせた構成・言葉選びを生成するために使われます。

### 内容情報

背景、現状、課題、原因、提案内容、結論、根拠、数値・データ、具体例、メリット、デメリット、リスク、対応策、スケジュール、役割分担、FAQに入れたい内容を入力します。

### 入れてほしい内容・避けたい内容

必ず入れたいキーワード・メッセージ・ページ、入れてはいけない内容、避けたい表現、機密度を指定します。業務利用時の品質と安全性を高めるための項目です。

### デザイン情報

資料の縦横比、配色、メインカラー、アクセントカラー、背景色、デザインの雰囲気、フォント、余白、文字量、画像の質、図解の量、イラスト、写真、アニメーションを指定します。

### 追加出力

チェックボックスで、1枚要約、Appendix、想定Q&A、送付メール文、スピーカーノート、ChatGPTでPowerPointファイル作成まで依頼する文言を選択できます。

## 生成されるプロンプトの説明

生成プロンプトには、以下の指示が含まれます。

- ChatGPTにビジネス資料作成の専門家として振る舞わせる指示
- 入力された情報のカテゴリ別整理
- 未入力項目を自然な前提で補完する指示
- 補完した前提を明記する指示
- 過度に断定的な表現を避ける指示
- ビジネス利用に耐える品質にする指示
- デザイン違いの3パターンを作成する指示
  - A案：端正でシンプルなビジネス資料
  - B案：コンサル風で整理された資料
  - C案：親しみやすく図解が多い資料
- 各スライドについて、スライド番号、タイトル、メッセージ、本文、図解案、デザイン指示、スピーカーノートを出力させる指示
- 追加出力オプションの反映
- 機密情報・個人情報・未確定情報に慎重な表現を求める注意事項
