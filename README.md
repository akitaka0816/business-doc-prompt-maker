# ビジネス資料設計プロンプトメーカー

ビジネス資料（提案書・研修資料・報告書など）を作成するためのChatGPT用プロンプトを、入力フォームから自動生成するWebアプリです。

このアプリ自体ではPowerPointファイルを作成しません。ChatGPT等のAIに資料設計を依頼するための、品質の高いプロンプトを組み立てるツールです。

## アプリ概要

- React + TypeScript + Vite で動くフロントエンド単体のアプリ
- バックエンド・外部API連携なし
- 入力内容はブラウザのlocalStorageに保存
- 入力フォームに沿って情報を整理 → ChatGPTに貼り付けるプロンプトを生成

## 起動方法

```bash
npm install
npm run dev      # 開発サーバを起動
npm run build    # 本番ビルド
npm run preview  # ビルド成果物のプレビュー
npm run lint     # Lint（任意）
```

ブラウザで `http://localhost:5173` を開きます。

## 使い方

1. 左側のフォームに、わかる範囲で情報を入力します（空欄でも構いません）。
2. カテゴリは折りたたみ可能です。最初は「基本情報」が開いています。
3. 右側のプレビューに、ChatGPT用プロンプトが自動で生成されます。
4. 「コピー」ボタンでプロンプトをクリップボードに保存します。
5. そのままChatGPTのチャット欄に貼り付けてください。
6. 入力内容はブラウザに自動保存されます。「JSONエクスポート」で書き出し、別端末で「JSONインポート」もできます。

## 入力項目の説明

入力フォームは7カテゴリで構成されています。

1. **基本情報** — 資料タイトル、種類、目的、対象者、利用シーン、使用言語、希望枚数、発表時間
2. **資料のゴール** — 一番伝えたいこと、相手に取ってほしい行動、判断してほしい事項、相手に残したい印象、成功の状態
3. **読み手情報** — 読み手の属性、前提知識、関心事、不安に思いそうな点、響く表現
4. **内容情報** — 背景、現状、課題、原因、提案内容、結論、根拠、数値・データ、具体例、メリット、デメリット、リスク、対応策、スケジュール、役割分担、FAQ
5. **入れてほしい内容・避けたい内容** — 必須キーワード／メッセージ／ページ、入れてはいけない内容、避けたい表現、機密度
6. **デザイン情報** — 縦横比、配色、メイン／アクセント／背景色、デザインの雰囲気、フォント、余白、文字量、画像の質、図解の量、イラスト、写真、アニメーション
7. **追加出力** — 1枚要約 / Appendix / 想定Q&A / 送付メール文 / スピーカーノート / PowerPoint作成依頼文 をチェックで選択

各入力欄の下には記入例が表示されます。空欄のまま生成した場合は、ChatGPT側で合理的に補完するよう指示が含まれます。

### 不足情報のやさしい補足

特に資料品質に効く下記項目が未入力の場合は、エラーではなく「品質向上のための補足」として案内が表示されます。

- 資料の目的 / 対象者 / 一番伝えたいこと / 課題 / 結論 / 希望枚数 / デザインの雰囲気

## 生成プロンプトの説明

生成されるプロンプトには、以下の指示が含まれます。

- 冒頭で「ビジネス資料作成の専門家として、そのまま使える資料を作成してください」と役割を指定
- 入力されたカテゴリ別の情報を整理して提示
- 未入力項目は合理的な前提で補完し、最後に「補完した前提一覧」を明記する指示
- **3パターンのデザイン**を必ず作成
    - A案：端正でシンプルなビジネス資料（白背景・ネイビー・グレー）
    - B案：コンサル風で整理された資料（比較表・マトリクス・ロードマップ活用）
    - C案：親しみやすく図解が多い資料（図解・アイコン・イラスト多め）
- 各スライドを、スライド番号 / タイトル / メッセージ / 本文 / 図解案 / デザイン指示 / スピーカーノート の形式で出力する指示
- 追加出力（1枚要約・Appendix・想定Q&A・送付メール文・PowerPoint作成依頼文）を選択に応じて追加
- 過度に断定的な表現を避け、機密情報・個人情報・未確定情報は慎重に扱うガイドライン

## 主要機能

- 入力フォーム（7カテゴリ・約60項目）
- 各項目に記入例（プレースホルダ＋下部キャプション）
- 空欄でも進める設計
- 不足情報チェック（やさしい補足表示）
- ChatGPT用プロンプト生成（リアルタイム反映）
- 生成プロンプトのプレビュー
- ワンクリックコピー
- localStorage保存
- 入力内容のJSONエクスポート／インポート
- リセット
- レスポンシブ対応（〜600px、〜960pxでレイアウト調整）
- 折りたたみ可能なカテゴリ
- 入力済み項目数の表示
